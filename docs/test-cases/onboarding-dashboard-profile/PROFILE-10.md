## Предусловия

- Есть авторизованный пользователь.
- Для кейсов онбординга используйте новый аккаунт без выбранного режима.
- Для кейсов с аватаром подготовьте хотя бы одно валидное изображение.

## Что проверяем

Изменения профиля сохраняются вместе и переживают refresh, relaunch и повторный логин.

## Чеклист

## Шаги проверки

1. Откройте <https://magic-sleep-time.duckdns.org/profile>.
2. Измените `Псевдоним (для публикаций)`.
3. Измените поле `О себе`.
4. При необходимости обновите аватар.
5. Обновите страницу.
6. Перезапустите приложение или выполните повторный вход.
7. Если у пользователя есть опубликованные истории, откройте публичную страницу автора.
8. Откройте каталог опубликованных историй и найдите карточку истории этого автора.
9. Откройте публичную страницу истории и проверьте author block.

- Изменения профиля сохраняются вместе и переживают refresh, relaunch и повторный логин.
