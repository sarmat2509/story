# LIB-12 Доступность премиум-голосов на бесплатном тарифе
[Назад к index](../README.md)


- ID: `LIB-12`
- Модуль: `Мои истории, экран чтения и серии`
- Приоритет: `P1`

## Точки входа

| Раздел | Web URL | Навигация внутри приложения |
| --- | --- | --- |
| Мои истории | <https://magic-sleep-time.duckdns.org/me/stories> | Раздел `Мои истории` |
| Старый маршрут | <https://magic-sleep-time.duckdns.org/library> | Старый маршрут должен вести в `Мои истории` |
| Просмотр своей истории | `https://magic-sleep-time.duckdns.org/me/stories/<storyId>` | Открыть карточку истории |
| Список серий | <https://magic-sleep-time.duckdns.org/me/series> | Раздел `Серии историй` |
| Детали серии | `https://magic-sleep-time.duckdns.org/me/series/<seriesId>` | Открыть карточку серии |

## Предусловия

- `FREE_ARTISAN_LIMIT_USER`
- Для `FREE_ARTISAN_LIMIT_USER` подготовлена своя история `DRAFT_STORY_NO_AUDIO_ES`.
- Язык истории у `DRAFT_STORY_NO_AUDIO_ES` = `es`.

## Что проверяем

На бесплатном тарифе список голосов для истории на языке `es` загружается, а премиум-голоса остаются заблокированными и ведут к paywall.

## Шаги проверки

1. Войдите под `FREE_ARTISAN_LIMIT_USER`.
2. Откройте `DRAFT_STORY_NO_AUDIO_ES` на экране чтения.
3. Откройте список голосов.
4. Найдите премиум-голоса.
5. Нажмите на один из заблокированных голосов.

## Ожидаемый результат

- Список голосов для `DRAFT_STORY_NO_AUDIO_ES` открывается и не показывает состояние `Не найдено доступних голосів`.
- В списке есть как минимум один заблокированный премиум-голос с явным визуальным состоянием недоступности.
- После нажатия на заблокированный премиум-голос пользователь не получает этот голос в selected state.
- Вместо выбора премиум-голоса пользователь видит paywall, CTA на апгрейд или другой явный сценарий обновления тарифа.
