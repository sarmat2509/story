## Предусловия

- Есть авторизованный пользователь.
- Для кейсов онбординга используйте новый аккаунт без выбранного режима.
- Для кейсов с аватаром подготовьте хотя бы одно валидное изображение.

## Что проверяем

Confirmation dialog защищает от случайного выхода.

## Шаги проверки

1. В профиле нажмите `Выйти`.
2. Один раз отмените действие.
3. Повторите и подтвердите выход.

## Критерии приемки
