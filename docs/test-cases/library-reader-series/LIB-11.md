## Предусловия

- Есть авторизованный пользователь с несколькими историями.
- Есть хотя бы одна история с аудио и одна без аудио.
- Есть хотя бы одна серия из нескольких частей.

## Что проверяем

Пользователь может прослушать сэмпл голоса до выбора.

## Шаги проверки

1. Откройте список голосов для истории без аудио.
2. Нажмите `Прослушать сэмпл` или `▶ Прослушать` у нескольких голосов.
3. Нажмите `Пауза` во время воспроизведения.
