## Предусловия

- Есть авторизованный пользователь.
- Для кейсов онбординга используйте новый аккаунт без выбранного режима.
- Для кейсов с аватаром подготовьте хотя бы одно валидное изображение.

## Что проверяем

Псевдоним сохраняется и используется в публикации.

## Чеклист

- [ ] Псевдоним сохраняется и используется в публикации.
- [ ] Новый псевдоним виден в профиле сразу после сохранения.
- [ ] Если открыть публикацию или шаринг для своей истории, в диалоге публикации используется актуальный псевдоним.
- [ ] Если у пользователя есть опубликованные истории, новый псевдоним проверяется на публичной странице автора, в каталоге опубликованных историй на карточках историй этого автора и в author block на странице публичной истории.
- [ ] После обновления страницы или повторного открытия сценария состояние остается согласованным.
- [ ] Во время выполнения сценария не возникает критических ошибок, сломанной верстки или необработанных состояний.

## Шаги проверки

1. Откройте <https://magic-sleep-time.duckdns.org/profile>.
2. Заполните поле `Псевдоним (для публикаций)`.
3. Нажмите кнопку сохранения.
4. Обновите страницу.
5. Откройте свою историю и проверьте диалог публикации или шаринга.
6. Если у пользователя есть опубликованные истории, откройте публичную страницу автора.
7. Откройте каталог опубликованных историй и найдите карточку истории этого автора.
8. Откройте публичную страницу истории и проверьте author block.

## Критерии приемки
