# LIB-16 Список серий и экран серии
[Назад к index](../README.md)


- ID: `LIB-16`
- Модуль: `Мои истории, экран чтения и серии`
- Приоритет: `P1`

## Точки входа

| Раздел | Web URL | Навигация внутри приложения |
| --- | --- | --- |
| Мои истории | <https://magic-sleep-time.duckdns.org/me/stories> | Раздел `Мои истории` |
| Старый маршрут | <https://magic-sleep-time.duckdns.org/library> | Старый маршрут должен вести в `Мои истории` |
| Просмотр своей истории | `https://magic-sleep-time.duckdns.org/me/stories/<storyId>` | Открыть карточку истории |
| Список серий | <https://magic-sleep-time.duckdns.org/me/series> | Раздел `Серии историй` |
| Детали серии | `https://magic-sleep-time.duckdns.org/me/series/<seriesId>` | Открыть карточку серии |

## Предусловия

- Есть авторизованный пользователь с несколькими историями.
- Есть хотя бы одна история с аудио и одна без аудио.
- Есть хотя бы одна серия из нескольких частей.

## Что проверяем

Части серии сгруппированы корректно.

## Чеклист

- [ ] Части серии сгруппированы корректно.
- [ ] Открывается правильный экран или страница без неожиданного редиректа или 404.
- [ ] Контент на странице соответствует выбранному объекту и сценарию перехода.
- [ ] Во время выполнения сценария не возникает критических ошибок, сломанной верстки или необработанных состояний.

## Шаги проверки

1. Откройте <https://magic-sleep-time.duckdns.org/me/series>.
2. Откройте одну серию.
3. Перейдите в одну из частей.

## Критерии приемки

- Части серии сгруппированы корректно.
- Открывается правильный экран или страница без неожиданного редиректа или 404.
- Контент на странице соответствует выбранному объекту и сценарию перехода.
- Во время выполнения сценария не возникает критических ошибок, сломанной верстки или необработанных состояний.
