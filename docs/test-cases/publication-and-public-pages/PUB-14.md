# PUB-14 Повторное голосование за ту же историю
[Назад к index](../README.md)


- ID: `PUB-14`
- Модуль: `Публикация и публичные страницы`
- Приоритет: `P2`

## Точки входа

| Раздел | Web URL | Навигация внутри приложения |
| --- | --- | --- |
| Каталог опубликованных историй | <https://magic-sleep-time.duckdns.org/stories> | Публичный раздел `Опубликованные истории` |
| Публичная история | `https://magic-sleep-time.duckdns.org/stories/<slug>` | Открыть карточку в каталоге |
| История по приватной ссылке | `https://magic-sleep-time.duckdns.org/u/<token>` | Открыть ссылку доступа |
| Публичная страница автора | `https://magic-sleep-time.duckdns.org/authors/<authorId>` | Нажать на блок автора в публичной истории |
| Своя история на экране чтения | `https://magic-sleep-time.duckdns.org/me/stories/<storyId>` | Открыть свою историю из `Мои истории` |

## Предусловия

- Есть авторизованный пользователь хотя бы с одной готовой историей.
- У пользователя заполнены псевдоним, аватар и `О себе` для проверки страницы автора.
- Подготовлены хотя бы одна публичная история и одна история по ссылке.

## Что проверяем

Одно и то же устройство или браузер не может бесконечно голосовать за одну и ту же историю.

## Шаги проверки

1. Откройте публичную историю и проголосуйте.
2. Обновите страницу.
3. Попробуйте проголосовать повторно.
