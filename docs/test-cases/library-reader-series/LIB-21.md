## Предусловия

- Есть авторизованный пользователь с несколькими историями.
- Есть хотя бы одна история с аудио и одна без аудио.
- Есть хотя бы одна серия из нескольких частей.

## Что проверяем

Генерация аудио корректно показывает очередь, повторную попытку после ошибки и сценарий апгрейда при лимите.

## Чеклист

- [ ] Генерация аудио корректно показывает очередь, повторную попытку после ошибки и сценарий апгрейда при лимите.
- [ ] Основной сценарий завершается успешно без сломанного UI или необработанной ошибки.
- [ ] Результат сценария виден пользователю на целевом экране и сохраняется после обновления страницы.
- [ ] Во время выполнения сценария не возникает критических ошибок, сломанной верстки или необработанных состояний.

## Шаги проверки

1. Откройте историю без готового аудио.
2. Запустите генерацию и зафиксируйте состояние очереди или обработки, если оно появляется.
3. Для истории с неудачной предыдущей генерацией проверьте сценарий `Попробовать снова`.
4. Для аккаунта с исчерпанным лимитом аудио повторите попытку генерации.

## Критерии приемки

- Генерация аудио корректно показывает очередь, повторную попытку после ошибки и сценарий апгрейда при лимите.
- Основной сценарий завершается успешно без сломанного UI или необработанной ошибки.

- Во время выполнения сценария не возникает критических ошибок, сломанной верстки или необработанных состояний.
