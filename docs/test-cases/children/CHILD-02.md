## Предусловия

- Есть авторизованный пользователь.
- Для кейсов анализа подготовьте хотя бы одно валидное фото ребенка.

## Что проверяем

Минимально валидный профиль ребенка можно создать.

## Шаги проверки

1. Откройте <https://magic-sleep-time.duckdns.org/children>.
2. Нажмите `Добавить ребёнка` или `Добавить профиль ребенка`.
3. Заполните только обязательные поля.
4. Нажмите `Сохранить`.
