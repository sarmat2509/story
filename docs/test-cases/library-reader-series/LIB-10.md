## Предусловия

- `PAID_AUDIO_USER`
- `DRAFT_STORY_NO_AUDIO_ES`
- Язык истории у `DRAFT_STORY_NO_AUDIO_ES` = `es`.
- Язык интерфейса можно оставить любым; кейс не проверяет переводы UI.

## Что проверяем

Список голосов для генерации аудио подгружается по языку истории и позволяет выбрать доступный голос.

## Шаги проверки

1. Войдите под `PAID_AUDIO_USER`.
2. Откройте `DRAFT_STORY_NO_AUDIO_ES` на экране чтения.
3. Дождитесь загрузки блока `Голос рассказчика`.
4. Откройте список голосов.
5. Выберите любой доступный голос.
6. Не закрывая экран истории, снова откройте список голосов.

## Ожидаемый результат

- На экране истории без аудио отображается блок `Голос рассказчика` до запуска генерации.
- После открытия списка голосов пользователь видит непустой список доступных голосов; состояние `Не найдено доступних голосів` не появляется.
- После выбора одного голоса этот голос отображается как текущий выбранный в блоке или trigger-кнопке списка.
- При повторном открытии списка тот же голос остается выбранным до запуска аудиогенерации или смены выбора.
