## Предусловия

- `REAL_APPLE_OAUTH_USER`
- OAuth Apple настроен в тестируемом окружении.
- У QA есть прямой доступ к реальному Apple-аккаунту `REAL_APPLE_OAUTH_USER`.

## Что проверяем

Вход через Apple работает стабильно и возвращает пользователя в приложение.

## Шаги проверки

1. Откройте <https://magic-sleep-time.duckdns.org/welcome>.
2. Нажмите `Войти через Apple`.
3. Завершите сценарий входа у провайдера под `REAL_APPLE_OAUTH_USER`.
4. Дождитесь возврата в приложение.
