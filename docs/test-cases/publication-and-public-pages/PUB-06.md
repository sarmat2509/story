# PUB-06 Просмотр каталога опубликованных историй
[Назад к index](../README.md)


- ID: `PUB-06`
- Модуль: `Публикация и публичные страницы`
- Приоритет: `P1`

## Точки входа

| Раздел | Web URL | Навигация внутри приложения |
| --- | --- | --- |
| Каталог опубликованных историй | <https://magic-sleep-time.duckdns.org/stories> | Публичный раздел `Опубликованные истории` |
| Публичная история | `https://magic-sleep-time.duckdns.org/stories/<slug>` | Открыть карточку в каталоге |
| История по приватной ссылке | `https://magic-sleep-time.duckdns.org/u/<token>` | Открыть ссылку доступа |
| Публичная страница автора | `https://magic-sleep-time.duckdns.org/authors/<authorId>` | Нажать на блок автора в публичной истории |
| Своя история на экране чтения | `https://magic-sleep-time.duckdns.org/me/stories/<storyId>` | Открыть свою историю из `Мои истории` |

## Предусловия

- `PUBLIC_AUTHOR_USER`
- Подготовлена фикстура `PUBLISHED_PUBLIC_STORIES_MULTI_LANGUAGE` минимум с 2 историями в каталоге.

## Что проверяем

Каталог опубликованных историй показывает карточки и базовую пагинацию без применения фильтров.

## Шаги проверки

1. Откройте <https://magic-sleep-time.duckdns.org/stories> как неавторизованный пользователь.
2. Убедитесь, что на экране видны карточки опубликованных историй.
3. Пролистайте список вниз до подгрузки следующей порции карточек.

## Ожидаемый результат

- Каталог открывается без авторизации и показывает список карточек опубликованных историй.
- На карточках видны обложка, заголовок и данные автора без пустых placeholder-блоков.
- При прокрутке вниз список либо подгружает дополнительные карточки, либо явно заканчивается без ошибки загрузки.
