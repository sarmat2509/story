## Предусловия

- Есть авторизованный пользователь с несколькими историями.
- Есть хотя бы одна история с аудио и одна без аудио.
- Есть хотя бы одна серия из нескольких частей.

## Что проверяем

Изменение скорости воспроизведения работает и отражается в UI.

## Шаги проверки

1. Откройте историю с готовым аудио.
2. Найдите блок `Скорость воспроизведения`.
3. По очереди переключите несколько значений скорости.
4. Прослушайте фрагмент после каждого изменения.
