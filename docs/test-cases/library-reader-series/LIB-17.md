## Предусловия

- Есть авторизованный пользователь с несколькими историями.
- Есть хотя бы одна история с аудио и одна без аудио.
- Есть хотя бы одна серия из нескольких частей.

## Что проверяем

Продолжение создает следующую часть в этой же серии.

## Чеклист

## Шаги проверки

1. Откройте eligible историю или экран серии.
2. Нажмите кнопку продолжения, например `Продолжить историю сейчас`.
3. Дождитесь создания новой части.
