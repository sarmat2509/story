## Шаги проверки

1. Откройте <https://magic-sleep-time.duckdns.org/wizard> под `FREE_INSTANT_LIMIT_USER`.
2. Выберите один сценарий.
3. Переключитесь на другой сценарий.
4. Запустите генерацию.
