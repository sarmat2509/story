## Предусловия

- Есть авторизованный пользователь с несколькими историями.
- Есть хотя бы одна история с аудио и одна без аудио.
- Есть хотя бы одна серия из нескольких частей.

## Что проверяем

На экране истории пользователь может перейти к предыдущей и следующей части серии.

## Шаги проверки

1. Откройте историю, которая входит в серию минимум из двух частей.
2. Найдите навигационный блок серии под историей.
3. Перейдите в предыдущую и затем в следующую часть.
