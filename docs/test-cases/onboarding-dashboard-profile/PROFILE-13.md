## Предусловия

- Есть авторизованный пользователь.
- Для кейсов онбординга используйте новый аккаунт без выбранного режима.
- Для кейсов с аватаром подготовьте хотя бы одно валидное изображение.

## Что проверяем

Пользователь может сменить режим в профиле, и новая точка входа в создание истории подстраивается под этот выбор.

## Шаги проверки

1. Откройте <https://magic-sleep-time.duckdns.org/profile>.
2. В блоке `Предпочтения` нажмите пункт с текущим режимом.
3. Смените режим, например с `Мгновенный режим` на `Мастерской режим`.
4. Вернитесь на главную и нажмите `Создать новую историю`.
