## App Name

WonderTales

## Subtitle / Short Description

Parent-managed AI stories for children, with illustrated characters, narration,
and safe sharing controls.

## Full Description

WonderTales helps parents create personalized illustrated stories for their
family. A parent or legal guardian creates the account, adds child profiles,
chooses story settings, and controls optional reference photos, narration,
sharing, purchases, data export, and deletion.

Create a story in minutes or use a guided setup to choose the theme, language,
mood, child profile, and characters. Children can read or listen in Child Mode
with the limits and access settings chosen by the parent.

Key features:

- Parent-managed child profiles and story setup
- Personalized illustrated stories with optional parent-provided reference photos
- Audio narration for story time
- Private-by-default library
- Parent controls for public stories, story generation, audio limits, and child access
- Report unsafe text, images, privacy concerns, or other issues in app
- Account, child-data, and privacy request flows

WonderTales does not replace faces in existing photos or videos and does not
create deceptive realistic media. Uploaded images are used only as optional
references to generate safe, fictional, illustrated story characters.

WonderTales is not a replacement for parental supervision. The app is designed
for adults to manage family storytelling settings and content.

## AI Content Notes

WonderTales uses AI to generate fictional story text, illustrated story images,
and optional narration based on parent-selected settings. Parents control child
profiles, uploaded reference images, generation settings, sharing, and deletion.

The app blocks disallowed use cases in product policy and provides in-app
reporting for unsafe images, unsafe text, privacy concerns, and other issues.
Reported generated content is queued for review and may be quarantined from
public surfaces while reviewed.

## Child Safety Notes

WonderTales is a parent-managed family storytelling app. A parent or legal
guardian creates the account, accepts Terms and Privacy, creates child profiles,
sets limits, controls purchases, controls image uploads, and decides whether
stories can be shared.

Children can read or listen to generated stories in Child Mode, subject to
parent settings. Child Mode does not expose billing, profile settings, plan
management, sibling private stories, or parent-only child profile management.

## Reviewer Notes

Use a parent reviewer account. Do not provide an admin account.

Suggested reviewer path:

1. Sign in with the provided parent reviewer credentials.
2. Open Dashboard and confirm the parent-managed onboarding / child profile.
3. Open Children, review the child profile and access settings.
4. Open Wizard and create or inspect a story for the seeded child profile.
5. Open a story and use Report issue to see the generated content report flow.
6. Open Plans to verify native subscription copy and restore purchases.
7. Open Profile to verify privacy export/deletion request and analytics consent controls.

Native subscriptions are purchased through App Store / Google Play via
RevenueCat. Web Stripe checkout is not used for native in-app purchases.
