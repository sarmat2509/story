## Шаги проверки

1. Откройте <https://magic-sleep-time.duckdns.org/profile>.
2. Заполните поле `О себе`.
3. Нажмите кнопку сохранения.
4. Обновите профиль.
5. Если у пользователя есть опубликованные истории, откройте публичную страницу автора.
