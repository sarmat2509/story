## Контекст

Этот набор нужно прогонять перед релизом, после крупных merge и после инфраструктурных изменений. Это самый короткий путь проверить, что приложение в целом остается рабочим.

## Что проверяем

Новый пользователь может зарегистрироваться и выбрать режим.

## Чеклист

- [ ] Новый пользователь может зарегистрироваться и выбрать режим.
- [ ] После регистрации открывается экран выбора режима, а после выбора пользователь попадает в авторизованную часть приложения.
- [ ] После обновления экрана сохраненные значения не теряются.

## Шаги проверки

1. Зарегистрируйте новый аккаунт по email.
2. Пройдите выбор режима.
