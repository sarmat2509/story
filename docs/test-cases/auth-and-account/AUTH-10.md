## Предусловия

- `REAL_MAILBOX_USER`
- У QA есть прямой доступ к inbox для `REAL_MAILBOX_USER`.

## Что проверяем

Пользователь может задать новый пароль по валидной ссылке из письма.

## Чеклист

- [ ] Пользователь может задать новый пароль по валидной ссылке из письма.
- [ ] Во время выполнения сценария не возникает критических ошибок, сломанной верстки или необработанных состояний.

## Шаги проверки

1. Запросите восстановление пароля для `REAL_MAILBOX_USER` через сценарий `Забыли пароль?`.
2. Откройте новое письмо в inbox `REAL_MAILBOX_USER`.
3. Перейдите по валидной ссылке из письма.
4. Введите новый валидный пароль.
5. Нажмите `Изменить пароль`.
6. Выполните вход с новым паролем.

## Критерии приемки

- Ссылка из последнего письма открывает экран сброса пароля без ошибки токена.
- Для `REAL_MAILBOX_USER` сохраняется новый пароль.
- После сохранения нового пароля вход под `REAL_MAILBOX_USER` с новым паролем проходит успешно.
- Во время выполнения сценария не возникает критических ошибок, сломанной верстки или необработанных состояний.
