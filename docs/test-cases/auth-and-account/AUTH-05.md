## Предусловия

- Есть доступ к тестовому почтовому ящику.
- OAuth-провайдеры настроены в тестируемом окружении.
- Подготовлены тестовые пользователи для email и OAuth сценариев.

## Что проверяем

Неверные credentials не авторизуют пользователя.

## Чеклист

- [ ] Неверные credentials не авторизуют пользователя.
- [ ] Сценарий входа завершается в ожидаемом состоянии без зависаний и частичной авторизации.
- [ ] Авторизованные разделы приложения становятся доступны корректному пользователю.
- [ ] Во время выполнения сценария не возникает критических ошибок, сломанной верстки или необработанных состояний.

## Шаги проверки

1. Введите неверный пароль для существующего email.
2. При необходимости повторите сценарий с несуществующим email.

## Критерии приемки

- Неверные credentials не авторизуют пользователя.
- Сценарий входа завершается в ожидаемом состоянии без зависаний и частичной авторизации.
- Авторизованные разделы приложения становятся доступны корректному пользователю.
- Во время выполнения сценария не возникает критических ошибок, сломанной верстки или необработанных состояний.
