# ARTISAN-11 Новая история появляется в «Моих историях»
[Назад к index](../README.md)


- ID: `ARTISAN-11`
- Модуль: `Создание истории в мастерском режиме`
- Приоритет: `P0`

## Точки входа

| Раздел | Web URL | Навигация внутри приложения |
| --- | --- | --- |
| Создание истории | <https://magic-sleep-time.duckdns.org/wizard> | Раздел `Создать` или кнопка `Создать новую историю` на главной |
| Мои истории | <https://magic-sleep-time.duckdns.org/me/stories> | Раздел `Мои истории` |
| Просмотр своей истории | `https://magic-sleep-time.duckdns.org/me/stories/<storyId>` | Открыть карточку истории из раздела `Мои истории` |
| Тарифы | <https://magic-sleep-time.duckdns.org/pricing> | Кнопка обновления тарифа на экране лимита или раздел `Тарифы` |

## Предусловия

- `FREE_ARTISAN_LIMIT_USER`
- Для выбора в мастере доступны `CHILD_MINIMAL` и `CHARACTER_PERSON` у `FREE_ARTISAN_LIMIT_USER`.

После успешной генерации история появляется в личной библиотеке.
