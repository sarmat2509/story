## Предусловия

- Есть авторизованный пользователь.
- Для кейсов анализа подготовьте хотя бы одно валидное фото ребенка.

## Что проверяем

Существующий профиль можно обновить без потери остальных данных.

## Чеклист

- [ ] Существующий профиль можно обновить без потери остальных данных.
- [ ] Обновленные данные видны в карточке ребенка и в форме повторного открытия профиля.
- [ ] После обновления экрана сохраненные значения не теряются.
- [ ] Во время выполнения сценария не возникает критических ошибок, сломанной верстки или необработанных состояний.

## Шаги проверки

1. Откройте существующий профиль ребенка.
2. Измените одно поле.
3. Нажмите `Сохранить`.
4. Откройте профиль повторно.

## Критерии приемки

- Существующий профиль можно обновить без потери остальных данных.
