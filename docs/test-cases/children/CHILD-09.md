- Есть авторизованный пользователь.
- Для кейсов анализа подготовьте хотя бы одно валидное фото ребенка.

## Чеклист

## Шаги проверки

1. Используйте аккаунт, достигший лимита профилей детей.
2. Попробуйте создать еще один профиль с главной и со страницы детей.
