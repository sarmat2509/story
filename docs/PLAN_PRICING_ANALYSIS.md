## Формула себестоимости (Director flow, 2026-03)

```
cost = base + 0.067 × scene_images + 0.02 × (llm_turnarounds + envs) + 0.004 × total_images + input_tokens
```

- **base** ≈ $0.055 (text_plain + director + validateScene)
- **scene_images** — сцены (Gemini output **$0.067/сцена**)
- **input_tokens** — промпт + reference images: **$0.50/1M** (Vertex AI Standard). aiUsageService считает inputUnits для image_generate.
- **llm_turnarounds** — LLM-персонажи без фото (Imagen 4 Fast: **$0.02/шт**)
- **envs** — окружения (Imagen 4 Fast: **$0.02/окружение**)
- **image_validation** ≈ $0.004/картинка
