## Предусловия

- Есть авторизованный пользователь.
- Для кейсов анализа подготовьте хотя бы одно валидное фото ребенка.

## Что проверяем

Анализ фото заполняет подсказки профиля и не ломает форму.

1. Откройте форму создания или редактирования ребенка.
2. Загрузите фото.
3. Дождитесь завершения анализа.
4. Проверьте предложенные значения перед сохранением.
