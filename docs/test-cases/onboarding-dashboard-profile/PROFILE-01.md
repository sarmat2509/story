## Предусловия

- Есть авторизованный пользователь.
- Для кейсов онбординга используйте новый аккаунт без выбранного режима.
- Для кейсов с аватаром подготовьте хотя бы одно валидное изображение.

## Что проверяем

Новый пользователь должен выбрать режим до продолжения работы.

## Шаги проверки

1. Зарегистрируйте новый аккаунт.
2. Дождитесь первого авторизованного экрана.
3. Выберите `Мгновенный режим` и завершите сценарий.
4. Повторите с `Мастерской режим`.
