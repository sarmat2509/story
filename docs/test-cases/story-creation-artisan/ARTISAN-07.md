## Точки входа

| Раздел | Web URL | Навигация внутри приложения |
| --- | --- | --- |
| Создание истории | <https://magic-sleep-time.duckdns.org/wizard> | Раздел `Создать` или кнопка `Создать новую историю` на главной |

## Предусловия

- `FREE_ARTISAN_LIMIT_USER`
- Для выбора в мастере доступны `CHILD_MINIMAL` и `CHARACTER_PERSON` у `FREE_ARTISAN_LIMIT_USER`.

## Что проверяем

При неудачной генерации пользователь получает понятный сценарий восстановления.

## Чеклист

- [ ] При неудачной генерации пользователь получает понятный сценарий восстановления.
- [ ] Основной сценарий завершается успешно без сломанного UI или необработанной ошибки.
- [ ] Результат сценария виден пользователю на целевом экране и сохраняется после обновления страницы.
- [ ] Во время выполнения сценария не возникает критических ошибок, сломанной верстки или необработанных состояний.

## Шаги проверки

1. Используйте окружение или данные, которые воспроизводят ошибку генерации.
2. Проверьте экран ошибки.
3. Если доступно, откройте `Сообщить о проблеме`.
