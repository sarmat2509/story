## Предусловия

- `REAL_MAILBOX_USER`
- У QA есть прямой доступ к inbox для `REAL_MAILBOX_USER`.

## Что проверяем

Недействительная ссылка на сброс обрабатывается безопасно.

## Чеклист

- [ ] Недействительная ссылка на сброс обрабатывается безопасно.
- [ ] Во время выполнения сценария не возникает критических ошибок, сломанной верстки или необработанных состояний.

## Шаги проверки

1. Запросите письмо на восстановление пароля для `REAL_MAILBOX_USER`.
2. Откройте письмо в inbox `REAL_MAILBOX_USER`.
3. Один раз успешно используйте ссылку из письма.
4. Попробуйте открыть ту же ссылку повторно или измените один символ в ссылке перед открытием.

## Критерии приемки

- Повторно использованная или измененная ссылка не открывает валидный экран смены пароля.
- Пользователь видит безопасное сообщение о невалидной или просроченной ссылке без server error и без входа в аккаунт.
- Во время выполнения сценария не возникает критических ошибок, сломанной верстки или необработанных состояний.
