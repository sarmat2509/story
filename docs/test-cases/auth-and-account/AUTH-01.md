## Предусловия

- Есть доступ к тестовому почтовому ящику.
- OAuth-провайдеры настроены в тестируемом окружении.
- Подготовлены тестовые пользователи для email и OAuth сценариев.

## Что проверяем

Новый аккаунт создается, пользователь попадает в авторизованную часть приложения.

## Чеклист

- [ ] Новый аккаунт создается, пользователь попадает в авторизованную часть приложения.
- [ ] Аккаунт создается без серверных и валидационных ошибок.
- [ ] Пользователь попадает в корректную авторизованную часть приложения.
- [ ] Во время выполнения сценария не возникает критических ошибок, сломанной верстки или необработанных состояний.

## Шаги проверки

1. Откройте <https://magic-sleep-time.duckdns.org/register> или перейдите на <https://magic-sleep-time.duckdns.org/welcome> и нажмите `Зарегистрироваться с помощью email`.
2. Введите уникальный валидный email и валидный пароль.
3. Нажмите кнопку `Зарегистрироваться`.

## Критерии приемки

- Новый аккаунт создается, пользователь попадает в авторизованную часть приложения.
