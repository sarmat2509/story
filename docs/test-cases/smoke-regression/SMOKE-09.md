# SMOKE-09 Изменения профиля сохраняются
[Назад к index](../README.md)


- ID: `SMOKE-09`
- Модуль: `Smoke-регрессия`
- Приоритет: `P1`

## Контекст

Smoke-кейс ограничен экраном профиля. Публичная проверка автора вынесена в отдельные кейсы публикации и не входит в этот smoke-сценарий.

## Что проверяем

Поля `Псевдоним (для публикаций)` и `О себе` сохраняются и остаются неизменными после refresh профиля.

## Точки входа

| Раздел | Web URL | Навигация внутри приложения |
| --- | --- | --- |
| Профиль | <https://magic-sleep-time.duckdns.org/profile> | Раздел `Профиль` |

## Предусловия

- `PROFILE_EDIT_USER`
- Базовые значения аккаунта до старта кейса: псевдоним `Profile QA`, `О себе` = `Profile baseline bio`.

## Шаги проверки

1. Войдите под `PROFILE_EDIT_USER` и откройте <https://magic-sleep-time.duckdns.org/profile>.
2. В поле `Псевдоним (для публикаций)` введите `Smoke QA Alias` и нажмите `Сохранить`.
3. В поле `О себе` введите `Smoke QA Bio` и нажмите `Сохранить`.
4. Обновите страницу или повторно откройте экран профиля.

## Ожидаемый результат

- После сохранения поле `Псевдоним (для публикаций)` содержит точное значение `Smoke QA Alias`.
- После сохранения поле `О себе` содержит точное значение `Smoke QA Bio`.
- После refresh оба поля показывают те же значения без отката к старому состоянию и без очистки полей.

## Cleanup

1. В поле `Псевдоним (для публикаций)` верните значение `Profile QA` и нажмите `Сохранить`.
2. В поле `О себе` верните значение `Profile baseline bio` и нажмите `Сохранить`.
