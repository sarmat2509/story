## Предусловия

- Есть авторизованный пользователь.
- Для кейсов онбординга используйте новый аккаунт без выбранного режима.
- Для кейсов с аватаром подготовьте хотя бы одно валидное изображение.

## Что проверяем

Удаление аватара возвращает fallback-состояние.

## Чеклист

- [ ] Удаление аватара возвращает fallback-состояние.
- [ ] Удаленный объект исчезает из списков и больше не доступен в связанных сценариях.
- [ ] После обновления экрана удаленное состояние сохраняется.
- [ ] Во время выполнения сценария не возникает критических ошибок, сломанной верстки или необработанных состояний.

## Шаги проверки

1. Используйте аккаунт с уже загруженным аватаром.
2. Откройте <https://magic-sleep-time.duckdns.org/profile>.
3. Нажмите `Удалить аватар`.
4. Обновите страницу.

## Критерии приемки

- Удаление аватара возвращает fallback-состояние.
- Удаленный объект исчезает из списков и больше не доступен в связанных сценариях.
- После обновления экрана удаленное состояние сохраняется.
- Во время выполнения сценария не возникает критических ошибок, сломанной верстки или необработанных состояний.
