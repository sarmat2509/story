## Предусловия

- Есть авторизованный пользователь.
- Для кейсов онбординга используйте новый аккаунт без выбранного режима.
- Для кейсов с аватаром подготовьте хотя бы одно валидное изображение.

## Что проверяем

Выбранный режим сохраняется после refresh и повторного логина.

## Чеклист

- [ ] Выбранный режим сохраняется после refresh и повторного логина.
- [ ] Сохраненный режим виден в профиле и определяет, какой сценарий открывает кнопка `Создать новую историю`.
- [ ] После обновления экрана сохраненные значения не теряются.
- [ ] После обновления страницы или повторного открытия сценария состояние остается согласованным.

## Шаги проверки

1. Сохраните режим.
2. Обновите страницу или перезапустите приложение.
3. Выйдите и снова войдите.
