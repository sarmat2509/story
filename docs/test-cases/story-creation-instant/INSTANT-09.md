- `FREE_INSTANT_LIMIT_USER`
- Подготовлены одно или несколько валидных изображений для загрузки.

## Что проверяем

Пользователь может выбрать возрастную группу перед генерацией, и выбранное значение не сбрасывается до отправки.

## Шаги проверки

1. Откройте <https://magic-sleep-time.duckdns.org/wizard> под `FREE_INSTANT_LIMIT_USER`.
2. По очереди переключите несколько возрастных групп.
3. После этого загрузите фото и выберите сценарий.
4. Убедитесь, что выбранная возрастная группа сохранилась до нажатия `Создать сказку`.
