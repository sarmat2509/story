# Артефакты для историй

Список рассчитан на два сценария: короткое название можно использовать прямо в тексте истории, а описание для генератора можно отдавать агенту для создания изображения карточки артефакта.

## Общий стиль карточек

Разрешение: заказывать минимальное доступное квадратное изображение для экономии генерации и передачи данных. Если генератор требует конкретный размер, использовать `1024x1024 px` как целевой минимум и сохранять пропорцию 1:1.

Единый художественный стиль: полуреалистичная сказочная предметная иллюстрация, один маленький артефакт в центре кадра, чистый светлый фон цвета теплой бумаги, мягкий студийный свет, аккуратная контактная тень под предметом, четкий силуэт, детализированные материалы, легкое магическое свечение только там, где оно описано в артефакте.

Запреты для всех карточек: без текста, без логотипов, без рамок интерфейса, без рук, без персонажей, без окружения комнаты, без нескольких разных предметов, кроме случаев, где связка предметов явно указана в описании.

Базовый шаблон промпта: `{Описание для генератора}. Полуреалистичная сказочная предметная иллюстрация, один маленький артефакт в центре, теплый бумажный фон, мягкий студийный свет, аккуратная контактная тень, четкий силуэт, квадрат 1:1, минимальное доступное квадратное изображение, без текста, без рук, без персонажей.`
