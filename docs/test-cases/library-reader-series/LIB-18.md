## Предусловия

- Есть авторизованный пользователь с несколькими историями.
- Есть хотя бы одна история с аудио и одна без аудио.
- Есть хотя бы одна серия из нескольких частей.

## Что проверяем

Пользователь может подписаться на автоматические продолжения истории с разной периодичностью и потом отменить эту подписку.

## Чеклист

- [ ] Пользователь может подписаться на автоматические продолжения истории с разной периодичностью и потом отменить эту подписку.
- [ ] Основной сценарий завершается успешно без сломанного UI или необработанной ошибки.
- [ ] Результат сценария виден пользователю на целевом экране и сохраняется после обновления страницы.
- [ ] После обновления страницы или повторного открытия сценария состояние остается согласованным.
- [ ] Во время выполнения сценария не возникает критических ошибок, сломанной верстки или необработанных состояний.

## Шаги проверки

1. Откройте историю или экран серии, где доступно расписание продолжений.
2. По очереди проверьте варианты периодичности, включая `каждый день`, `через день`, `два раза в неделю` и `раз в неделю`.
3. Сохраните один из вариантов.
4. Обновите экран.
5. Проверьте, что отображается следующая дата или явный статус активного расписания.
6. Отмените расписание.
