## Предусловия

- `PAID_AUDIO_USER`
- `DRAFT_STORY_NO_AUDIO_ES`
- Язык истории у `DRAFT_STORY_NO_AUDIO_ES` = `es`.

## Что проверяем

Сэмпл голоса воспроизводится для языка текущей истории до выбора голоса.

## Шаги проверки

1. Войдите под `PAID_AUDIO_USER`.
2. Откройте `DRAFT_STORY_NO_AUDIO_ES` на экране чтения.
3. Откройте список голосов.
4. Нажмите `Прослушать сэмпл` или `▶ Прослушать` у любого доступного голоса.
5. Дождитесь старта воспроизведения.
6. Нажмите `Пауза`.

## Ожидаемый результат

- У каждого доступного голоса есть управляющий элемент для запуска сэмпла.
- После нажатия на `Прослушать сэмпл` начинается воспроизведение preview без `404`, пустого аудио или зависшего состояния.
- Во время проигрывания UI переключается из `Прослушать сэмпл` в состояние паузы или активного воспроизведения.
- После нажатия `Пауза` воспроизведение останавливается, а UI возвращается в паузу или исходное состояние без перезагрузки экрана.
- Для истории `DRAFT_STORY_NO_AUDIO_ES` проигрывается сэмпл языка истории `es`, а не украинский sample по умолчанию.
