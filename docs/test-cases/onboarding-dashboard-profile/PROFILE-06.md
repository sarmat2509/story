## Предусловия

- Есть авторизованный пользователь.
- Для кейсов онбординга используйте новый аккаунт без выбранного режима.
- Для кейсов с аватаром подготовьте хотя бы одно валидное изображение.

## Что проверяем

Загрузка аватара обновляет профиль и публичные поверхности автора.

## Шаги проверки

1. Откройте <https://magic-sleep-time.duckdns.org/profile>.
2. Нажмите `Добавить аватар` или `Изменить аватар`.
3. Выберите валидное изображение.
4. Обновите профиль.
5. Если у пользователя есть опубликованные истории, откройте публичную страницу автора.
6. Откройте публичную страницу любой истории этого автора и проверьте author block.
