## Предусловия

- Есть авторизованный пользователь.
- Для кейсов онбординга используйте новый аккаунт без выбранного режима.
- Для кейсов с аватаром подготовьте хотя бы одно валидное изображение.

## Что проверяем

После смены языка ключевые экраны и кнопки отображаются на выбранном языке без смешения локалей.

## Шаги проверки

1. Откройте <https://magic-sleep-time.duckdns.org/profile>.
2. Нажмите `Настройки языка`.
3. Выберите другой поддерживаемый язык.
4. Проверьте минимум следующие экраны: `Главная`, `Мои истории`, `Тарифы`, `Профиль`, экран входа и публичный каталог историй.
5. Проверьте ключевые кнопки, например `Войти`, `Зарегистрироваться`, `Создать новую историю`, `Сообщить о проблеме`, `Обновить план`.

## Критерии приемки
