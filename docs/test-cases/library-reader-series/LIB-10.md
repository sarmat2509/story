## Предусловия

- Есть авторизованный пользователь с несколькими историями.
- Есть хотя бы одна история с аудио и одна без аудио.
- Есть хотя бы одна серия из нескольких частей.

## Что проверяем

Пользователь может выбрать голос рассказчика перед генерацией аудио.

## Шаги проверки

1. Откройте историю без аудио.
2. Найдите блок `Голос рассказчика`.
3. Откройте список голосов.
4. Выберите один доступный голос.
5. Запустите генерацию аудио.
