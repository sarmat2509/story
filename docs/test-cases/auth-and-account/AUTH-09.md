## Предусловия

- `REAL_MAILBOX_USER`
- У QA есть прямой доступ к inbox для `REAL_MAILBOX_USER`.

## Что проверяем

Отправка письма для восстановления пароля работает.

## Чеклист

- [ ] Отправка письма для восстановления пароля работает.

## Шаги проверки

1. Откройте <https://magic-sleep-time.duckdns.org/welcome>.
2. Нажмите `Забыли пароль?`.
3. Введите email от `REAL_MAILBOX_USER`.
4. Нажмите `Отправить ссылку`.

## Критерии приемки

- На экране отображается подтверждение отправки письма без server error.
- В inbox `REAL_MAILBOX_USER` приходит новое письмо для восстановления пароля.
- Письмо содержит ссылку на сброс пароля для текущего окружения.
- Во время выполнения сценария не возникает критических ошибок, сломанной верстки или необработанных состояний.
