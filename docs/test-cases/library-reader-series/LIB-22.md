## Предусловия

- Есть авторизованный пользователь с несколькими историями.
- Есть хотя бы одна история с аудио и одна без аудио.
- Есть хотя бы одна серия из нескольких частей.

## Что проверяем

Библиотека помнит режим отображения и аудио-фильтр, а переход из истории по сценарию открывает уже отфильтрованный список.

## Чеклист

- [ ] Библиотека помнит режим отображения и аудио-фильтр, а переход из истории по сценарию открывает уже отфильтрованный список.
- [ ] Сценарий входа завершается в ожидаемом состоянии без зависаний и частичной авторизации.
- [ ] Авторизованные разделы приложения становятся доступны корректному пользователю.
- [ ] После обновления страницы или повторного открытия сценария состояние остается согласованным.
- [ ] Во время выполнения сценария не возникает критических ошибок, сломанной верстки или необработанных состояний.

## Шаги проверки

1. Откройте <https://magic-sleep-time.duckdns.org/me/stories>.
2. Переключите режим карточек и включите фильтр `Только с аудио`.
3. Обновите страницу.
4. Из открытой истории перейдите по breadcrumb сценария обратно в библиотеку, если он отображается.
