## Предусловия

- Есть авторизованный пользователь с несколькими историями.
- Есть хотя бы одна история с аудио и одна без аудио.
- Есть хотя бы одна серия из нескольких частей.

## Что проверяем

На экране своей истории пользователь может сохранить LLM-персонажа, сгенерированного внутри истории, в свой общий список персонажей.

## Чеклист

- [ ] На экране своей истории пользователь может сохранить LLM-персонажа, сгенерированного внутри истории, в свой общий список персонажей.
- [ ] Открывается правильный экран или страница без неожиданного редиректа или 404.
- [ ] Контент на странице соответствует выбранному объекту и сценарию перехода.
- [ ] После обновления страницы или повторного открытия сценария состояние остается согласованным.
- [ ] Во время выполнения сценария не возникает критических ошибок, сломанной верстки или необработанных состояний.

## Шаги проверки

1. Откройте свою историю, где отображается блок персонажей.
2. Найдите персонажа, которого не было заранее в пользовательском списке `Персонажи`.
3. Нажмите `Сохранить персонажа` у этого персонажа.
4. Перейдите в раздел `Персонажи`.
5. При необходимости откройте создание новой истории и проверьте, что сохраненный персонаж доступен для выбора.
