## Предусловия

- `PAID_AUDIO_USER`
- Для `PAID_AUDIO_USER` подготовлена своя история `DRAFT_STORY_NO_AUDIO_ES`.
- Язык истории у `DRAFT_STORY_NO_AUDIO_ES` = `es`.

## Что проверяем

На платном тарифе премиум-голос можно выбрать для истории на языке `es` и использовать для запуска аудиогенерации.

## Шаги проверки

1. Войдите под `PAID_AUDIO_USER`.
2. Откройте `DRAFT_STORY_NO_AUDIO_ES` на экране чтения.
3. Откройте список голосов.
4. Выберите премиум-голос.
5. Запустите генерацию аудио.

## Ожидаемый результат

- В списке голосов для `DRAFT_STORY_NO_AUDIO_ES` премиум-голоса отображаются без locked-состояния.
- После выбора премиум-голос становится текущим выбранным голосом в блоке `Голос рассказчика`.
- После запуска генерации аудио начинается обычный flow генерации без paywall и без ошибки `Не найдено доступних голосів`.
- После успешного завершения на экране истории появляется аудиоплеер или playback controls.
