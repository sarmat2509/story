## Шаги проверки

1. Откройте <https://magic-sleep-time.duckdns.org/profile>.
2. Нажмите `Сообщить о проблеме`.
3. Дождитесь открытия модалки после подготовки скриншота.
4. Проверьте, что превью скриншота появилось автоматически.
5. Нажмите `Заменить скриншот`, выберите другое изображение и затем протестируйте `Удалить скриншот`.
6. Заполните обязательные поля и отправьте форму.
