## Предусловия

- Есть авторизованный пользователь с несколькими историями.
- Есть хотя бы одна история с аудио и одна без аудио.
- Есть хотя бы одна серия из нескольких частей.

## Что проверяем

Аудио-виджеты отображаются в правильных состояниях и мини-плеер ведет себя предсказуемо.

## Чеклист

- [ ] Аудио-виджеты отображаются в правильных состояниях и мини-плеер ведет себя предсказуемо.
- [ ] Элементы управления отражают фактическое состояние аудио и работают предсказуемо.
- [ ] Сценарий выполняется без битых ссылок, зависшего плеера или сброса состояния без причины.
- [ ] Во время выполнения сценария не возникает критических ошибок, сломанной верстки или необработанных состояний.

## Шаги проверки

1. Откройте историю с готовым аудио.
2. Запустите воспроизведение.
3. Перейдите в другой раздел приложения.
4. Вернитесь обратно в историю.
