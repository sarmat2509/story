# PUB-18 Фильтр по языку истории
[Назад к index](../README.md)


- ID: `PUB-18`
- Модуль: `Публикация и публичные страницы`
- Приоритет: `P1`

## Что проверяем

Фильтр языка в каталоге опубликованных историй показывает только истории с выбранным языком.

## Точки входа

| Раздел | Web URL | Навигация внутри приложения |
| --- | --- | --- |
| Каталог опубликованных историй | <https://magic-sleep-time.duckdns.org/stories> | Публичный раздел `Опубликованные истории` |

## Предусловия

- `PUBLIC_AUTHOR_USER`
- Подготовлены фикстуры `PUBLISHED_PUBLIC_STORY_UK` и `PUBLISHED_PUBLIC_STORY_ES`.
- Обе истории опубликованы в каталог и видимы в <https://magic-sleep-time.duckdns.org/stories>.

## Шаги проверки

1. Откройте <https://magic-sleep-time.duckdns.org/stories>.
2. Зафиксируйте карточки `PUBLISHED_PUBLIC_STORY_UK` и `PUBLISHED_PUBLIC_STORY_ES` в исходном списке.
3. Откройте dropdown фильтра языка.
4. Выберите `es`.
5. Дождитесь обновления списка.
6. Снова откройте dropdown фильтра языка и выберите `uk`.
7. Дождитесь обновления списка.
8. Верните значение фильтра на `Все языки`.

## Ожидаемый результат

- В панели фильтров каталога есть отдельный dropdown языка истории.
- После выбора `es` карточка `PUBLISHED_PUBLIC_STORY_ES` остается в списке, а карточка `PUBLISHED_PUBLIC_STORY_UK` исчезает.
- После выбора `uk` карточка `PUBLISHED_PUBLIC_STORY_UK` остается в списке, а карточка `PUBLISHED_PUBLIC_STORY_ES` исчезает.
- После возврата на `Все языки` в каталоге снова доступны истории обоих языков.
